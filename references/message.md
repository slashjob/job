# Messaging

One message to one person on LinkedIn, for the purpose the invocation names. The deliverable is
that message typed into LinkedIn and left unsent — invariant 1 covers Send as much as Submit.

**This is the one action that opens a profile, and only the one named.** The user chose this person
and is about to turn up in their inbox anyway. A sign-in page is theirs to get past: ask, naming the
tab, and wait.

## Who

A profile URL, or a name. A name is looked for in `contacts` first; one matching several rows is
asked about. A name held nowhere is searched on LinkedIn with whatever the purpose says about them
— the company, the role — and where more than one result could be them, ask, listing each with
their title.

## For what

**The purpose is the user's, as the invocation states it.** With none stated, ask. Where a reference
covers that purpose, read it before writing:

| Purpose | Read |
| ------- | ---- |
| A referral to a posting | `references/referral.md` |
| A company in the news | `references/news.md`, **Writing to a lead** |

## Which box

| Path | Where the message goes |
| ---- | ---------------------- |
| 1st | Message, on their profile |
| Anyone else | Connect, then the note LinkedIn offers to add to the request |

**A connection note is capped at a few hundred characters, and LinkedIn counts them.** Write to the
count rather than letting it cut the ask off the end. Free accounts get a handful of notes a month:
when LinkedIn says they are used up, stop and say so.

**A Message button that opens InMail or a Premium offer is not a way in.** Never spend a credit or
start a trial.

**Read the thread before writing to a 1st.** It is the only record of how well the two know each
other — a 1st can be a close friend or a stranger accepted years ago — and a message that introduces
the user to someone they wrote to last month reads as a mail merge. If the thread already holds an
unanswered ask for the same thing, stop and say so rather than adding a second.

## What it says

1. **Why this person** — the path: the mutual connection by name, the school, the group, as the
   `contacts` row or the profile shows it. It is the reason a stranger reads the second sentence.
   Never claim an acquaintance the row, the profile and the thread do not show; a 1st with a history
   needs no path at all.
2. **The purpose**, and what in the user's record makes it worth their time.
3. **One ask**, with a no that costs them nothing.

**Nothing about them the profile does not show.** Praise for a career or a post is the mark of mass
outreach, and the reader has seen it that morning.

**A message is short enough to read on a phone without scrolling** — four or five sentences. A
stranger owes the user nothing and reads accordingly.

**Cordial and professional**: a greeting by first name, a polite ask, and a sign-off of "Best," and
the user's first name on their own lines. A connection note's sign-off counts against the cap, so
the middle is the first thing cut to make room.

## Hand it over

Type it into the box and stop, with the tab left open. Under the opening sentence, the message as
typed, so they can ask for a change without leaving the conversation; a change is retyped in the
same box.

## Adding a quirk

What LinkedIn turned out to need — where Connect hides, what the note box refuses — earns a line
here once it is driven.

- **The note box's label says 300 characters; its counter, and the real cap on a free account, is
  200.** Write to the counter. Newlines count.
