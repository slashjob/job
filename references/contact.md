# Contacting

One message to one person the network action found, about one role: why the role fits the user, and
a request to refer them if the contact agrees. The deliverable is that message typed into LinkedIn
and left unsent — invariant 1 covers Send as much as Submit.

**This is the one action that opens a profile, and only the one named.** The user chose this person
and is about to turn up in their inbox anyway. A sign-in page is theirs to get past: ask, naming the
tab, and wait.

## Who, and for which role

The person is a row in `contacts`, named by profile URL or by name. A name matching more than one
row is asked about. **A person not held is not written to** — the row is what says how the user
reaches them — so offer `/job network` for their company instead.

The role is the posting named. With none named it is the company's one posting that is
`shortlisted`, `staged`, `applied` or `interviewing`; with several, ask which, by title. **A posting
at a company other than the contact's is a mistake to raise, not a message to write.**

## Which box

| Path | Where the message goes |
| ---- | ---------------------- |
| 1st | Message, on their profile |
| Anyone else | Connect, then the note LinkedIn offers to add to the request |

**A connection note is capped at a few hundred characters, and LinkedIn counts them.** Write to the
count rather than letting it cut the ask off the end. Free accounts get a handful of notes a month:
when LinkedIn says they are used up, stop and say so.

**A Message button that opens InMail or a Premium offer is not a way in.** Never spend a credit or
start a trial.

**Read the thread before writing to a 1st.** It is the only record of how well the two know each
other — a 1st can be a close friend or a stranger accepted years ago — and a message that introduces
the user to someone they wrote to last month reads as a mail merge. If the thread already holds an
unanswered ask about this role, stop and say so rather than adding a second.

## What it says

Three things, in this order, and nothing else:

1. **Why this person** — the path as the row holds it: the mutual connection by name, the school,
   the group. It is the reason a stranger reads the second sentence. Never claim an acquaintance the
   row and the thread do not show; a 1st with a history needs no path at all.
2. **The role and the match** — the title as the posting spells it, with the posting's URL where the
   box has room, since a referral names an opening. Then what the posting asks for most and the one
   or two things in the record that meet it: the match, by the same rule as a fit question in
   `references/applying.md`, not the resume retold.
3. **The ask** — a referral if, having read that, they think the fit is real, with a no that costs
   them nothing. One ask.

**Say where the application stands, as the posting's `status` has it** — in already, or about to go
in. Some employers only take a referral made before the application, so the contact needs to know
which.

**A recruiter or the hiring manager is not asked for a referral**: they are who a referral goes to.
Tell them the application is in, or coming, and the match, and ask only that they look at it.

**Nothing about them the row does not hold.** Praise for a career or a post is the mark of mass
outreach, and the reader has seen it that morning.

**A message is short enough to read on a phone without scrolling** — four or five sentences. A
stranger owes the user nothing and reads accordingly.

**Cordial and professional**: a greeting by first name, a polite ask, and a sign-off of "Best," and
the user's first name on their own lines. A connection note's sign-off counts against the cap, so
the match is the first thing cut to make room.

## Hand it over

Type it into the box and stop, with the tab left open. Under the opening sentence, the message as
typed, so they can ask for a change without leaving the conversation; a change is retyped in the
same box.
